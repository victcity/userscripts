# 自用油猴脚本集合

个人维护的 Tampermonkey 用户脚本。需先安装 [Tampermonkey](https://www.tampermonkey.net/)，点击下方脚本链接即可安装。

## 脚本列表

### [Bilibili UP主黑名单屏蔽器](./bilibili-up-blocker.user.js)

B 站增强脚本，一个脚本四件事：

- **拉黑UP主**——主页 / 视频页推荐 / 热门页卡片一键「屏蔽」，实时隐藏其全部视频与直播推荐卡、广告卡，取消即时恢复，隐藏后卡片自动补位不留空白
- **黑名单面板**——搜索、粘贴主页链接快速添加、导入/导出备份、一键清空，面板可拖动
- **评论区 IP 属地**——评论时间旁展示 IP 属地（含楼中楼，重构自 mscststs「B站评论区开盒」）
- **视频旋转缩放**——视频页工具栏注入控制条：四档旋转（90° 自动适配画面）、步进/滚轮无级缩放、原地编辑百分比、一键重置

控制台调试句柄：`__bcr.stats()` / `__bcr.list()` / `__bcr.togglePanel()`

### [DeepSeek 会话正文样式定制](./deepseek-chat-styler.user.js)

自定义 chat.deepseek.com 会话正文样式：宽度、字体、字号、行高、字重、斜体、粗体颜色、代码块字体。右下角 **Aa** 按钮打开设置，即时生效并自动保存。
