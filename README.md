# 自用油猴脚本集合

个人在用的 Tampermonkey（油猴）用户脚本仓库。

## 脚本列表

### DeepSeek 会话正文样式定制

适用于 [chat.deepseek.com](https://chat.deepseek.com/) 的会话正文样式定制脚本，可自定义正文的宽度、字体、字号、行高、字重、斜体、粗体颜色与代码块字体。

#### 功能

- **正文宽度**：600–1600px 或 30%–100% 百分比（px / % 一键切换），也可铺满整个内容区；调整后消息列表仍保持水平居中
- **正文字体**：内置 系统无衬线、黑体、宋体/衬线、仓耳今楷、楷体、仿宋、Georgia、等宽 等预设，支持手动输入自定义字体（自定义优先于预设）
- **字号**：12–28px
- **行高**：1.2–2.6
- **字重**：300–700
- **斜体**：开关
- **粗体着色**：为正文中的 `**粗体**`（`strong`/`b`）自定义颜色
- **代码块字体**：内置 系统等宽、Comic、JetBrains Mono、Source Code Pro 等预设，支持手动输入自定义字体
- 所有设置即时生效并自动保存（`GM_setValue`，异常环境回退 `localStorage`），跨刷新持久

#### 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 安装本脚本，任选其一：
   - 直接点击 [`deepseek-chat-styler.user.js`](./deepseek-chat-styler.user.js) 的原始文件链接（Raw），Tampermonkey 会自动弹出安装页；
   - 或打开 Tampermonkey 面板 →「添加新脚本」，粘贴文件全部内容并保存。

#### 使用

打开 [chat.deepseek.com](https://chat.deepseek.com/)，点击页面右下角 **Aa** 悬浮按钮打开设置面板，调整即时生效；也可通过 Tampermonkey 菜单中的「打开正文样式设置」进入。点击「恢复默认」可一键还原。

#### 实现说明

- DeepSeek 正文的列宽由消息列表容器（`.ds-virtual-list-items`）上的 CSS 变量 `--message-list-max-width` 配合 `calc((100% - var(--message-list-max-width)) / 2)` 控制限宽与居中，脚本直接覆盖该变量实现任意宽度，因此不依赖构建哈希类名，站点发版不易失效；
- 字体规则直接命中 `.ds-message` / `.ds-markdown` 并以 `!important` 覆盖站点自带样式（仅靠继承会被 `.ds-markdown` 自身规则压住）；
- 设置面板挂在 Shadow DOM 中，不受站点样式污染；面板被 SPA 重渲染挤掉时会自动重建。

### Bilibili UP主黑名单屏蔽器

B站（bilibili.com）增强脚本：一键拉黑UP主并实时隐藏其视频与直播推荐卡、评论区展示IP属地、视频画面旋转与缩放。

#### 功能

- **UP主黑名单**：主页 / 视频页推荐列表 / 热门页的视频卡片上带「屏蔽」按钮，点击即拉黑该UP主并实时隐藏其所有视频卡片，取消拉黑即时恢复（无需刷新）；主页的直播推荐楼层卡与广告卡自动隐藏，隐藏后后续卡片自动补位、不留空白
- **黑名单管理面板**：Tampermonkey 菜单打开；支持按昵称/UID 搜索、手动添加（支持直接粘贴 space.bilibili.com 主页链接）、一键清空、导出/导入备份（剪贴板 JSON）、面板可拖动、Esc 关闭，列表显示「昵称 + UID」
- **评论区 IP 属地**：评论区（含楼中楼）在时间旁展示 IP 属地；重构合并自 mscststs 的「B站评论区开盒」（ISC License），覆盖新旧多代评论组件
- **视频画面旋转与缩放**：视频页工具栏注入控制条——0°/90°/180°/270° 旋转、±5% 步进缩放、点击原地编辑百分比、滚轮无极微调（Shift 1% 精调）、一键重置；90°/270° 自动计算适配缩放
- UP主识别以纯 DOM 提取为主（主页/视频页零 API 请求）；热门页卡片无UP主链接，采用 bvid→mid 持久缓存 + 0.8s 限速串行队列补齐，失败不写缓存
- 动态内容由单一 MutationObserver（去抖）+ 3s 兜底扫描驱动，无轮询循环

#### 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 安装本脚本，任选其一：
   - 直接点击 [`bilibili-up-blocker.user.js`](./bilibili-up-blocker.user.js) 的原始文件链接（Raw），Tampermonkey 会自动弹出安装页；
   - 或打开 Tampermonkey 面板 →「添加新脚本」，粘贴文件全部内容并保存。

#### 使用

- 在任意 B 站页面点击卡片上的「屏蔽」按钮拉黑UP主；Tampermonkey 菜单 →「打开/关闭黑名单管理器」管理黑名单；
- 控制台诊断句柄：`__bcr.stats()` / `__bcr.list()` / `__bcr.togglePanel()`。

#### 实现说明

- 新版主页作者链接类名由 `--author` 改为 `--owner`，mid 直接从 DOM 提取，零 API 依赖；
- 隐藏目标必须取外层 `.feed-card`（栅格子元素）：误藏内层 `.bili-feed-card` 会留下被拉伸的永久空白格；
- 新版视频页的 Vue 应用对管理容器内的外来子节点极敏感——页面挂载完成前插入节点会引发 `bili-header.umd.js` 被重复加载、顶栏挂载失败变空白。因此：视频页卡片的「屏蔽」按钮用 CSS 伪元素渲染（`dataset` 属性选择器，自定义 class 会被 Vue 重写抹掉），点击走坐标事件委托；旋转控制条等顶栏真实渲染完成并过 6 秒稳定期后，才以 `flex` 占位形式嵌套进工具栏（新版 `.video-toolbar-left` / 老版 `.arc_toolbar_report` 双兼容），滚动天然跟手；
- 评论 IP 属地功能必须在页面主世界运行（拦截脚本插入、劫持 `bbComment` 全局注册、对 Vue3/lit 两代评论脚本做源码补丁），通过函数序列化 + `<script>` 注入实现，与油猴沙箱中的 GM_* API 互不干扰；
- 黑名单数据（UID 数组）沿用旧版存储键，跨版本升级不丢数据。
